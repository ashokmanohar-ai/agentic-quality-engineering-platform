# Limitations

- Model outputs remain probabilistic and depend on the source requirement.
- Mock responses prove workflow mechanics, not semantic capability of a production model.
- Provider adapters need organisation-specific rate limiting, budgets, regions, and data policy.
- Generated automation remains a proposal requiring review.
- Failure triage is probabilistic; confidence is not accuracy.
- SQLite is not the recommended high-concurrency production database.
- Local JWT is intentionally small and should be replaced by enterprise OIDC.
- Lexical retrieval is a measurable baseline, not a claim of best-in-class RAG.
- Browser examples use self-contained pages; real systems need environment and data adapters.
- A release recommendation is evidence for organisational governance, not a replacement for it.
