# Security Policy

## Supported version

Security fixes target the latest release on `main`.

## Reporting

Please use GitHub private vulnerability reporting for this repository. Include affected version, reproducible steps, impact, and a minimal safe proof. Do not open a public issue for an unpatched vulnerability and never include credentials, tokens, personal data, or customer content.

## Scope

Relevant reports include authentication/authorisation bypass, project/tenant data exposure, prompt-to-tool escalation, path traversal, arbitrary command execution, secret leakage, approval bypass, artifact-hash bypass, and unsafe dependency or container behavior.
